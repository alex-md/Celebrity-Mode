# Celebrity Mode

A RuneLite plugin that lets you experience life as a Gielinor icon. Whether you are grinding skills on an empty world or just nostalgic for the classic era when turning Private Chat to "On" flooded your screen, Celebrity Mode spawns an entourage of client-side simulated players who follow you, crowd your tiles, and shower you with adoration.

## Features

- **Client-Side Entourage:** Spawns simulated players locally using RuneLite's `RuneLiteObject` API (100% cosmetic, zero network packets or server interaction).
- **Dynamic Swarming & Pathfinding:** Followers trail behind you, match your run/walk cadence, and disperse naturally around your resting tile without stacking into a single pile.
- **Classic Nostalgic Overhead Chat:** Fans frequently shout authentic era-appropriate lines (`"OMG IS THAT REALLY YOU?!"`, `"Can I have 100k?"`, `"@@@@@@@@@@@@"`, `"Sign my shield pls"`, `"wave2:glow:FREE STUFF PLS"`).
- **Configurable Fame Levels:**
  - Crowd size (1–30 followers).
  - Follower gear themes (Level 3 Bob defaults, F2P Bronze/Iron noobs, Mid-game whip warriors, Bankstanders).
  - Chat chatter frequency and support for custom shout lines.
- **Toggle on Demand:** Flip fame on or off instantly via plugin settings or a configured hotkey.

## Disclaimer

Celebrity Mode is entirely cosmetic and runs exclusively inside your local client. Spawned followers do not interact with game objects, real players, or the Jagex game servers.
